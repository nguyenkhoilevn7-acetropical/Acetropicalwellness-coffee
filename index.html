💳 Cài Đặt Tài Khoản Nhận Chuyển Khoản (VietQR / MoMo / ZaloPay)

Thông tin này sẽ tự động sinh mã VietQR và mã QR MoMo/ZaloPay để khách quét chuyển tiền trực tiếp vào tài khoản của bạn:

🚀 Tự Động Hóa 100%: Cập Nhật Thực Đơn Thẳng Lên GitHub (1 Cú Click)

Để khi bạn bấm Lưu món mới hay Sửa giá trên máy tính/điện thoại của bạn mà mọi điện thoại của khách quét mã QR đều nhận ngay tức thì (không cần tải file thủ công), bạn chỉ cần dán GitHub Token 1 lần duy nhất vào đây:

👉 Cách lấy mã Token (chỉ mất 1 phút): Mở link Tạo GitHub Token ➔ Đặt hạn dùng No expiration (hoặc tùy ý) ➔ Cuộn xuống bấm Generate token màu xanh ➔ Sao chép mã bắt đầu bằng ghp_... dán vào ô trên.
